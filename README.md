# Ceep

App Android de notas: crie notas com título e descrição e veja todas em lista.

## Telas

- `ListNoteActivity`: lista de notas
- `FormNoteActivity`: criar nota (título e descrição)

## Stack

Kotlin, AndroidX AppCompat, Material Components e ConstraintLayout. minSdk 16.

## Como rodar

Abra no Android Studio e rode o módulo `app`.
